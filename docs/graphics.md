# 그림 텍스트 목록 (1차, 2026-10-27)

문자열이 아니라 그림(텍스처)에 그려진 일본어. 번역 범위는 D3 "텍스트 전부 + 자주 보이는 그림 텍스트"이며, 이 목록은 그 범위를 정하기 위한 자료다.

## 형식과 도구
- 그림은 DAT000.cpk 안의 `.pix`(1,579개): FPIX 컨테이너 → DPIX 표 → XPIX 항목마다 Sony **GIM** 텍스처. 해독은 `tools/pix.py`(컨테이너), `tools/gim.py`(RGBA8888·인덱스4/8·팔레트·PSP 스위즐, 픽셀 시작 = 헤더 +0x1C).
- 텍스처 15,491개, 내용(해시) 기준 고유 4,277개. 2D(FLASH·ID·MEDIA) 고유 3,270개, 3D(STAGE·PLAYER·EFFECT·OBJECT) 1,007개(이번 조사 범위 밖).
- **이벤트 그림 파일마다 공통 UI 그림의 사본이 들어 있음.** 예: 하단 조작 안내 아틀라스는 527개 파일에 똑같이 들어 있음. 한 장을 고치려면 같은 해시의 사본을 모두 바꿔야 함(해시로 일괄 교체 가능).
- 재현: `python3 scripts/gfx/gfx_dump.py FLASH/ID/g_menu.pix ...`(텍스처 PNG), `scripts/gfx/gfx_sheets.py`(고유 2D 텍스처 시트 41장), `gfx_label_score.py`·`gfx_label_crops.py`(장소 표시 후보). 출력은 work/gfx(저장소 밖).
