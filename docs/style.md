# 번역 규칙·말투

원칙(D4): **고유명사는 한국 정발 만화를 기준으로 통일하고, 대사와 문체는 원작의 인물성과 관계를 유지하면서 자연스러운 현대 한국어로 번역한다.**

표 안의 상태가 `승인`·`잠정승인`인 항목만 초벌 기준으로 쓴다. 표본 검수(D4-7)가 끝나기 전에는 대량 초벌을 하지 않는다.
고유명사·용어는 `text/glossary.tsv`가 기준이다(`잠정승인` = 정발판 실물 대조 대기).
각 항목 ID는 승인·변경 이력을 추적하는 데 쓴다.

## 0. 번역 스타일 가이드 v1.0 (프로젝트 소유자 승인, 2026-10-26, D5)

이 절이 최우선 기준이다. 아래 §1–§4 표는 근거·세부 규칙이며, 충돌하면 이 절을 따른다.

### 고유명사
- 한국 정발 만화의 고유명사를 최우선으로 사용한다.
- 로이 머스탱이 에드워드를 「鋼の」라고 부를 경우 반드시 '강철의'로 번역한다.
- お父様는 '아버님'으로 통일한다.
- ホムンクルス는 '호문쿨루스'를 기본으로 사용하며 정발판 표기 확인 전까지 병기 방식은 잠정 적용한다.

### 인물별 말투
- 에드워드: 직설적인 반말, 다혈질. 불필요한 욕설 추가 금지.
- 알폰스: 온화하고 예의 바른 말투. 가까운 인물에게는 자연스러운 반말.
- 로이: 평상시 여유로운 반말, 심각한 상황에서는 짧고 단호한 어조.
- 호크아이: 에드·알에게 사적으로는 해요체 사용 가능. 군 공식 상황에서는 관계와 상황에 맞는 격식체.
- 휴즈: 다정하고 친근한 말투. 가족 이야기에 감정이 드러남.
- 올리비에: 위압적이고 냉정함. 윗사람에게는 존대 형식을 유지할 수 있으나 명령의 강도는 약화하지 않는다.
- 알렉스 암스트롱: '이 몸'을 대표적인 1인칭으로 사용. 과장되고 호쾌한 말투.
- 킴블리: 정중하고 지적인 존댓말. 잔혹한 발언에서도 차분함을 유지.
- 란팡: 충직하고 절제된 말투. 일본어 가타카나 외국인 억양을 어색한 한국어로 재현하지 않는다.
- 녹스: 신경질적이고 거친 구어체. 원문의 감정 강도를 유지한다.

### 문장 규칙
1. 원문의 의미와 장면의 감정선을 우선한다.
2. 일본어 문장 구조를 기계적으로 보존하지 않는다.
3. 과도한 의역, 유행어, 인터넷 밈을 추가하지 않는다.
4. 정발 만화와의 용어 일관성을 유지한다.
5. 캐릭터의 존댓말·반말 관계를 장면별로 일관되게 적용한다.
6. 튜토리얼 설명은 '~합니다', 행동 권유는 '~해 보세요'를 기본으로 한다.
7. 게임 내 텍스트 길이 제한과 제어 기호를 준수한다.
8. 의미가 불분명한 문장은 임의로 확정하지 않고 검수 대상으로 표시한다.
9. 화자의 성격과 대사 목적을 고려하여 욕설의 강도를 유지한다.
10. 인물 호칭은 번역 과정에서 임의로 변경하지 않는다.

## 4. 검수 기준 (D4)

- 직역으로 일본어 문장 구조를 따라가지 않는다. 불필요한 현대 유행어를 쓰지 않는다.
- 에드워드: 직설적·다혈질, 진지한 장면에서는 감정의 깊이를 살린다.
- 알폰스: 온화하고 예의 바름, 에드와는 자연스러운 형제 관계.
- 머스탱: 여유롭고 지적. 군인으로서의 명령과 사적인 농담을 구분.
- 호크아이: 절제되고 정확. 군대식 표현을 남발하지 않음.
- 올리비에: 냉정·강압적 지휘관. 원문에 없는 욕설 추가 금지.
- 호문쿨루스: 각자의 성격과 위계를 반영, 같은 악역 말투로 통일하지 않음.
