# 번역 규칙·말투 (초안)

상태: **제안** — 사람 승인 전에는 대량 초벌에 쓰지 않는다(decisions D3).
고유명사·용어는 `text/glossary.tsv`가 기준이다(정발판 표기 우선, D3).
각 항목 ID는 승인·변경 이력을 추적하는 데 쓴다.

## 2. 제어 기호 (변경 금지·위치 규칙)

| 토큰 | 의미 | 규칙 |
|---|---|---|
| `<~VOICE_ID>` | 음성 재생 | 순서·개수·위치(페이지 첫머리) 그대로 |
| `@n` | 줄바꿈 | 한국어 줄나눔에 맞게 옮길 수 있음. 한 페이지 최대 4줄(관찰값), 줄 폭은 한글 기준 미확정 |
| `⊥` | 페이지 넘김(대사 계속) | 개수·순서 유지(음성 큐와 짝이 맞음) |
| `⊿` | 대사 끝 | 마지막에 하나, 유지 |
| `@c<NN>` `@s<NNN>` | 색·속도(EBOOT 튜토리얼) | 색을 입힐 낱말을 감싸는 위치로 옮기되 개수·인자 유지 |
| `<~P>` | (mes_j 시스템 문구) | 유지, 의미 미확인 |
| `⊇` `仝` 등 기호 | PSP 버튼·상표 그림 글자 | 그대로 |
