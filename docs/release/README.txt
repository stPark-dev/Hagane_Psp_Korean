강철의 연금술사 FULLMETAL ALCHEMIST 약속의 날로 (PSP) 한글패치 v0.9 베타
==========================================================================

비상업 팬 번역입니다. 판매하거나, 패치를 적용한 ISO를 배포하지 마십시오.
원작·게임 저작권: (C) 荒川弘/鋼の錬金術師製作委員会・MBS (C) 2010 NBGI(현 반다이남코)


■ 0.9 베타의 상태
- 대사 전체(약 12,600줄), 메뉴·UI, 시스템 화면(세이브 정보 등), 화면 속 그림 글자
  (타이틀 로고, 장 제목, 장소 표시, 메뉴 그림)를 한국어로 바꿨습니다.
- 번역은 초벌 상태입니다. 사람의 전체 검수 전이라 어색한 표현이나 오역이 있을 수 있습니다.
- PPSSPP(에뮬레이터)에서 확인했습니다. 실제 PSP에서는 아직 확인하지 못했습니다.
- 고유명사는 국내 정발 만화 표기를 기준으로 했습니다(에드, 알, 로이 머스탱, 리올 등).


■ 필요한 것
원본: 鋼の錬金術師 FULLMETAL ALCHEMIST 約束の日へ (일본판, ULJS00292) UMD를 덤프한 ISO
  크기   1,528,987,648 바이트
  CRC32  38C73614
  MD5    90ff8e7765ac60bdc66d3f28ee1c3c86
  SHA-1  90bb6519636e8f6cc82d5942fc65de0e70cfba0b
해시가 다르면 패치가 적용되지 않습니다. CSO 등으로 압축했다면 ISO로 되돌린 뒤 적용하십시오.


■ 적용 방법
1) xdelta UI(윈도우) 또는 Delta Patcher를 실행합니다.
   - Patch: Hagane_Yakusoku_KR_v0.9.xdelta
   - Source File: 원본 ISO
   - Output File: 원하는 이름.iso
2) 명령줄(리눅스·맥):
   xdelta3 -d -s "원본.iso" Hagane_Yakusoku_KR_v0.9.xdelta "한글판.iso"
3) 결과 ISO의 해시는 CHECKSUMS.txt와 같아야 합니다.


■ 주의 사항
- 설치 기능(메모리스틱 데이터 설치)을 쓰지 마십시오. 0.9는 설치 데이터를 지원하지 않습니다.
  예전에 설치한 데이터가 있으면 게임이 그 일본어 데이터를 읽어 화면이 섞입니다.
  메모리스틱의 PSP/SAVEDATA/ULJS00292HAGINS 폴더를 지운 뒤 실행하십시오.
- 실기 PSP는 커스텀 펌웨어(CFW)가 필요할 수 있습니다(실기 미확인).
- 일본판으로 만든 세이브 데이터와의 호환은 확인하지 못했습니다. 새로 시작하는 것을 권합니다.


■ 알려진 문제
- 오프닝 영상 끝의 타이틀 로고, 컷인 그림 속 편지·신문 글씨는 일본어 그대로입니다.
- 전투 중 일부 팝업(능력 저하, 체인 러시)은 게임 화면에서 확인하지 못했습니다.
- 대화창 3줄에 맞추느라 일부 대사를 줄였습니다(검수 예정).
